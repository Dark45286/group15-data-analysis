# Data Analysis with Python - Crop Recommendation

## Overview
This project performs data analysis on crop recommendation datasets using Python. The analysis includes exploring soil fertility indices, environmental factors, and their relationships with crop recommendations.

## Project Contents
- **Group 15_Data_Analysis_with_Python_cro_Recommendation.ipynb** - Jupyter notebook containing the complete data analysis workflow
- **Data-Analysis-with-Python.pptx** - Presentation slides documenting the analysis and findings

## Technologies Used
- Python 3
- pandas - Data manipulation and analysis
- numpy - Numerical computing
- matplotlib - Data visualization

## Dataset
The analysis uses `Crop_recommendation.csv` which contains:
- Soil nutrient levels (N, P, K)
- Environmental factors (temperature, humidity, pH, rainfall)
- Crop recommendations based on these factors

## Key Features
- Data exploration and preprocessing
- Soil fertility index calculation
- Statistical analysis of environmental factors
- Crop recommendation patterns
- Data visualization

## Getting Started

### Prerequisites
```bash
pip install pandas numpy matplotlib jupyter
```

### Running the Analysis
1. Clone this repository
2. Ensure the dataset `Crop_recommendation.csv` is in the same directory
3. Open the Jupyter notebook:
```bash
jupyter notebook "Group 15_Data_Analysis_with_Python_cro_Recommendation.ipynb"
```
4. Run all cells to reproduce the analysis

## Analysis Workflow
1. Data loading and initial exploration
2. Data shape and structure analysis
3. Feature engineering (soil fertility index)
4. Statistical summaries and insights
5. Visualization and interpretation
